## Features
- Low power design! 3V operating voltage
- On board square wave generator
- Selectable features through solder bridges
- A Schematic on the front side!

## How to build
Just order the PCB & components, open up the KiCAD file and build it accordingly.

## BOM
- 1 	Battery holder
- 1 	10uF Capacitor
- 11	PNP Transistor
- 11	NPN Transistor
- 1 	100k Resistor
- 1 	10k Resistor
- 10	4.7k Resistor
- 3 	220 Resistor
- 2 	Potentiometer
- 1 	Push Button
